## الدورة الإلزامية بعد كل مهمة

| # | الخطوة | التفصيل |
|---|---|---|
| 1 | **اختبار** | تشغيل الاختبارات المناسبة للمرحلة (Unity Play Mode / سكربتات / فحوص ثابتة) |
| 2 | **مراجعة** | `git status` + فحص الملفات المؤقتة والأسرار قبل أي commit |
| 3 | **Commit** | رسالة واضحة: ماذا ولماذا، ونتيجة الاختبار |
| 4 | **Push** | `master` مباشرة — **بدون Force أبدًا** |
| 5 | **تحقق** | `git ls-remote origin` يرجّع نفس الـSHA + استنساخ/جلب تحقّق |
| 6 | **تقرير** | المُنجَز · الاختبارات ونتائجها · رقم الـcommit · تأكيد الرفع |

## قواعد حماية (غير قابلة للتفاوض)

- ❌ **Force Push** ممنوع في أي حالة.
- ❌ **حذف/استبدال** ملفات موجودة بدون موافقة صريحة.
- ❌ **رفع أسرار**: كلمات مرور · Tokens · مفاتيح خاصة · ملفات ترخيص Unity (`*.alf`, `Unity_lic.ulf`) · `.git-credentials` · `.netrc`.
- ❌ **رفع ملفات مولَّدة/ضخمة** ممكن إعادة إنشاؤها (bundles, zips, `Library/`, `bin/`, `obj/`) إلا لو مطلوبة للمشروع.
- ❌ **Commit لتغييرات غير مختبرة** على أنها «نسخة مستقرة».
- ✅ **Tag** عند إكمال كل مرحلة رئيسية: `phase4-4-...` / `baseline-...`.
- ✅ **لو الرفع فشل**: التغييرات تفضل محليًا + إبلاغ بالسبب الحقيقي. **مفيش ادعاء إن النسخة الاحتياطية اتحدثت.**

## حالة الاختبارات في البيئة الحالية (شفافية)

- **مفيش Unity ولا dotnet/csc** في الساندبوكس ⇒ اختبارات Play Mode **غير قابلة للتشغيل** الآن.
- لما الاختبار ما يتنفذش: التغيير **ما يُوسمش** كـ«مستقر» ولا ياخد Tag، والتقرير بيقول صراحة «غير مختبر».
- الاختبارات القابلة للتنفيذ حاليًا: فحص بصمات (`sha256sum`)، توازن أقواس/سلاسل لكود C#،
  تحقق سلامة الأرشيف (`unzip -t`)، فحص أسرار (`git grep` على أنماط)، واختبار استرجاع (`git clone` من GitHub).

## الأدوات

```bash
# بعد أي مهمة (من جوه مساحة العمل):
./tools/sync_to_github.sh "رسالة الـcommit الواضحة"
```
السكربت: يجلب `master` من GitHub → يزامن ملفات المساحة (استبعاد الأسرار/الضخم) → فحص أسرار →
commit → push بدون force → تحقق بالـSHA.
