## 1. المعلومات الأساسية

```
عنوان اللعبة:
الملخص في سطر واحد:
الشعور العام (٣ كلمات):        مثال: بارد / قريب / مسدود
المرجع السينمائي:              مثال: Sicario + Prisoners + Drive
المرجع في الألعاب:             Detroit / Heavy Rain / Life is Strange
```

## 2. البطل

```
الاسم:
العمر:
مهنة/دور:
عايز إيه (Want):
محتاج إيه فعلاً (Need):
أكبر خوف عنده:
أكبر كذبة بيقولها لنفسه:
```

## 3. الشخصيات الأخرى (كرّر لكل شخصية)

```
الاسم:                  الدور في الحكاية:
عمر:                    صلة بالبطل:
سره:                    اللي بيخفيه حتى عن نفسه:
موقفه من البطل:         حليف / خصم / متذبذب / مرآة
هل ممكن يموت؟           نعم/لا — وفي أنهي نقطة
```

## 4. الفصول

```
الفصل ١ — العنوان:
  المكان:
  الهدف الظاهر للبطل:
  ما يحدث فعلاً:
  القرار المحوري (نقطة اللا رجعة):

الفصل ٢ — ... (كرّر)

الفصل ٣ — ...
```
