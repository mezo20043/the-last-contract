## 2. إنشاء الشخصيات الواقعية (Character Pipeline)

هنا الفلوس بتتحرق. الطريق الموصى به:

```
[CC4 + Headshot]  →  [Blender: retopo/LOD]  →  [Substance Painter]  →  [Unity URP]
      ↓
  ARKit blendshapes + Game-base rig
      ↓
  [Mixamo / Cascadeur] للجسم   [Face Capture / Audio2Face] للوش   [Timeline] للتجميع
```

| الأداة | الاستخدام | التكلفة التقريبية |
|---|---|---|
| **Character Creator 4** (Reallusion) | إنشاء بشري واقعي، ريج + blendshapes جاهزة، تصدير FBX | ~$300–500 مرة واحدة |
| **Headshot 2** (إضافة CC) | توليد وش واقعي من صورة | ~$200 |
| **Blender 4.x** | retopo، LOD، تصليح الريج، بناء البيئة | مجاني |
| **Substance Painter** | تكستشر واقعي (جلد، قماش، معدن) | ~$20/شهر (Steam: شراء دائم) |
| **Cascadeur** | أنيميشن حركة واقعي بمساعدة فيزيائية — **الأهم في المشروع** | مجاني للاستخدام الفردي |
| **Mixamo** | مشيات أساسية (بتتعدّل بعدها) | مجاني |
| **Unity Face Capture** (iOS) | تسجيل تعبيرات وش واقعية من آيفون | مجاني |
| **Audio2Face-3D** | مزامنة شفايف من الصوت أوتوماتيك — بيوفر أسابيع | مجاني (NVIDIA) |
| **Unity Recorder** | تصدير السينمائيات لـ MP4/HEVC | مجاني |

> **قاعدة مهمة:** ما تشتريش أصول شخصيات جاهزة واقعية من Asset Store. وشوشها بتبان "Game Asset" فوراً في مشهد سينمائي قريب. الشخصيات الرئيسية لازم تكون متعملة خصيصاً بـ CC4.

## 3. البيئة (Environment Pipeline)

- **الوحدة الأساسية:** الغرفة. اللعبة في الفصل ١ كلها ٥ مساحات (شقة، ممر، قسم شرطة، ورشة، سطح).
- **البناء:** modular kit — كتل حوائط/أرضيات/أبواب بـ ٢م شبكة، مع ٣ مستويات تفصيل.
- **المواد:** Quixel Megascans (مجاني على Fab) للأرضيات والجلود والمعادن.
- **تقدير الحجم:** غرفة واحدة ≈ ٤٠–٨٠ ألف تريانج + ٨–١٢ مادة.
- **الإضاءة:** كل مشهد بإضاءة مخبوزة (Baked GI) + ٢–٣ ناقلات ضوء حقيقية كحد أقصى.

## 4. ميزانية الأداء على الموبايل (Mobile Budget) — الأرقام الحاكمة

| البند | iOS (iPhone 13+) | Android (SD 8 Gen 2) | الحد الأدنى (SD 855) |
|---|---|---|---|
| الإطارات | 60 | 60 | 30 |
| تريانجات في الكادر | 350k | 250k | 120k |
| شخصيات في الكادر | 4 | 3 | 2 |
| Draw Calls | 350 | 250 | 150 |
| مادة واحدة | ASTC 6x6 / 2K | ASTC 6x6 / 2K | ASTC 8x8 / 1K |
| ذاكرة تكستشر | 600 MB | 450 MB | 300 MB |
| ظلال حقيقية | ١ ضوء + كاش | ١ ضوء | blob shadow فقط |
| بعد المعالجة | Bloom + ACES + Vignette + Grain | نفسها بدون Grain | ACES فقط |
| حجم الحزمة الأساسية | ≤ 200 MB (AAB) | ≤ 200 MB | — |
| باقي المحتوى | Play Asset Delivery / On-Demand | نفسها | — |

### التريكات اللي بتحمي الأداء
1. **السينمائيات الثقيلة تتصدّر فيديو.** مشهد فيه ٥ شخصيات + إضاءة معقّدة؟ اعمله Timeline، اعمل له Render لـ MP4 HEVC 1080p، وشغّله كـ VideoPlayer. النتيجة أفخم من الريل تايم، وتكلفتها حجم ملف بس.
2. **الشخصيات: ٣ LOD + Skinned Mesh محدود ٤ عظام/فرتكس.**
3. **الإضاءة مخبوزة ١٠٠% في المشاهد الثابتة.** الريل تايم للشخصيات فقط.
4. **Volume-based additive scenes** — شقة واحدة في الذاكرة في المرة.
5. **مفيش realtime reflections.** Reflection Probes مخبوزة + SSR بس على الأرضيات الرخامية في المشاهد الحرجة.
