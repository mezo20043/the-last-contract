# تشغيل اللعبة على الأندرويد | Install on Android

## الطريقة الأولى — من المتصفح (الأسرع)

1. افتح رابط المعاينة في المتصفح على موبايلك.
2. من قائمة Chrome (⋮) → **Add to Home screen** → **Install**.
3. هتلاقي أيقونة **العقد الأخير** على شاشة الهوم. تفتحها تبقى ملء الشاشة زي أي تطبيق.

## الطريقة الثانية — ملف واحد يشتغل أوفلاين للأبد

ملف `index.html` **قائم بذاته بالكامل** — كل الصور والقصة جواه. معناها:

1. نزّل `index.html` على الموبايل (أو ابعتُه لنفسك على واتساب/تيليجرام).
2. افتحه بأي متصفح. بيشتغل من غير إنترنت خالص.
3. تقدمك بيتحفظ تلقائياً في المتصفح — اقفل وارجع وقت ما تحب.

## الطريقة الثالثة — استضافة مجانية (لو عايز تشاركها)

ارفع فولدر `game` كامل (فيه `index.html` + `manifest.json` + `sw.js` + الأيقونات) على:

- **Netlify Drop** — اسحب الفولدر على `app.netlify.com/drop` وخلاص.
- **GitHub Pages** — ارفع الفولدر وفعّل Pages.
- **Cloudflare Pages** — نفس الفكرة.

بعدها الرابط بيفتح مباشرة، والـ Service Worker بيخليها تشتغل أوفلاين بعد أول زيارة.
