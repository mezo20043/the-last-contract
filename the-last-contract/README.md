## إيه اللي اتعمل فعلاً

### ١. اللعبة نفسها — قابلة للعب
- واجهة عربية RTL موبايل-أولاً، خلفيات سينمائية + بورتريهات للشخصيات
- آلة كاتبة، انتقالات سينمائية، كروت فصول، مؤثرات صوتية توليدية
- ٣ عدّادات حيّة (الإنسانية / نادين / الحقيقة) بيتأثروا بقراراتك
- حفظ تلقائي — اقفل وارجع وقت ما تحب
- معرض نهايات بيفضل محفوظ بين المرات

### ٢. القصة — مكتوبة كاملة
آدم منصور، قاتل مأجور، بياخد آخر عقد قبل ما يسيب البلد.
الظرف فيه صورة. والصورة دي بتقلب تمن سنين.

### ٣. نظام السرد — بيانات مش كود
`game-src/story.json` هو المصدر الوحيد. المحرك بيقراه. تعديل حوار ≠ إعادة بناء.

### ٤. جاهزية النقل لـ Unity
نفس الـ JSON بيتقرأ في `unity/Assets/Scripts/` — المكتوب هناك مطابق للسكيما دي،
فلو قررت تعمل النسخة 3D، القصة بتتنقل من غير ما تتكتب تاني.

## بنية المشروع

```
the-last-contract/
├── game/                     ← اللعبة الجاهزة
│   ├── index.html            ← العب من هنا (قائم بذاته)
│   ├── manifest.json  sw.js  ← تثبيت PWA
│   ├── icon-192/512.png
│   └── README-ANDROID.md
├── game-src/
│   ├── story.json            ← القصة كبيانات
│   ├── bg/                   ← ٨ خلفيات
│   └── portraits/            ← ٦ بورتريهات
├── tools/
│   ├── build_story.py        ← يبني القصة + يتحقق من الروابط
│   └── build_game.py         ← يبني index.html
├── docs/
│   ├── CHARACTER-BIBLE.md    ← دستور الشخصيات (+ متغيرات وأرقام إنتاج)
│   ├── TOOLS-AND-PIPELINE.md ← Unity والأدوات وميزانية الأداء والفلوس
│   ├── PROJECT-SETUP.md      ← فتح مشروع Unity
│   └── STORY-INTAKE-TEMPLATE.md
└── unity/Assets/             ← نظام سرد C# جاهز (١٢ سكربت)
```

## إعادة البناء

```bash
python3 tools/build_story.py   # يتحقق من الشجرة
python3 tools/build_game.py    # يبني اللعبة
```
