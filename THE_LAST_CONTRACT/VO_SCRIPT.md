# سكربت التسجيل الصوتي — THE LAST CONTRACT

**80 سطر** موزّعة على 3 فصول.

> الملفات المطلوبة **مش موجودة** في المشروع — لازم تُسجَّل بصوت بشري.
> النظام جاهز: حط الملف باسم معرّف العقدة في `Resources/Audio/Voice/{nodeId}.wav`
> وبيتشغّل تلقائياً مع السطر (انظر `VoiceOverSystem`).

## المواصفات الفنية للتسجيل

| البند | القيمة |
|---|---|
| الصيغة | WAV · 24 kHz · 16-bit · أحادي (أو 48 kHz وأنا أحوّلها) |
| القص | بلا موسيقى خلفية · بلا ضجيج غرفة |
| المستوى | −18 LUFS تقريباً · القمة −3 dB |
| الصمت | 150 ms قبل وبعد كل سطر |
| تسمية الملف | `{nodeId}.wav` بالحرف |
